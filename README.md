📝 ToDo App – Simple, Elegant, and Productive Task Management

A clean and responsive ToDo application built with **React.js** and styled using **Tailwind CSS**, enabling users to effortlessly add, manage, and track their daily tasks. Designed for both usability and performance.

---

## 🚀 Features

- ✅ Add new tasks instantly
- 🗑️ Delete tasks with one click
- 🔁 Toggle task completion status
- 💾 LocalStorage support to persist data
- 📱 Fully responsive UI with Tailwind CSS
- ⚡ Lightweight and fast performance
